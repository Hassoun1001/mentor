# Methods Atlas

Nobody counts how many traders use each method, so no real census exists. The usage labels here are informed judgements. We based them on surveys where they exist, on what trading platforms and courses offer, and on published research. They are not measured percentages. Popularity and evidence are separate labels: a very popular method can still have weak evidence.
